# String Compressor (C++17/20)

Консольное приложение для многократного сжатия строки по правилу:  
**группы подряд идущих одинаковых символов заменяются на символ и количество повторений**.  
Сжатие повторяется до тех пор, пока строка не перестанет изменяться.

## Возможности

- Ввод строки тремя способами:
  - с клавиатуры
  - из текстового файла (первая строка)
  - генерация случайной строки заданной длины (с вероятностью появления групп повторов)
- Циклическое текстовое меню, защита от некорректного ввода
- Вывод:
  - исходной и сжатой строки
  - длин строк
  - количества сэкономленных символов и процента сжатия
  - сообщения об отсутствии повторов
- Обработка ошибок (пустая строка, недопустимые символы, ошибки файла, превышение итераций)

## Ограничения программы

| Ограничение | Значение |
----------------------------------------------------------
| Максимальная длина входной строки | **10 000 символов** |

| Максимальное число итераций сжатия | **1000** |

| Допустимые символы | **только латинские буквы (a-z, A-Z)** |

| Генерация случайной строки | **длина от 1 до 1000** |


## Требования

- Компилятор с поддержкой C++17 (или C++20)

## Сборка

g++ -std=c++17 main.cpp string_compressor.cpp -o program.exe


./program.exe
